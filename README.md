# 🌍 Get Set Go – AI-Powered Travel Companion App

[![Made with Flutter](https://img.shields.io/badge/Made%20with-Flutter-blue?logo=flutter)](https://flutter.dev)
[![Powered by Gemini API](https://img.shields.io/badge/Powered%20by-Gemini%20API-orange?logo=google)](https://ai.google.dev)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)

**Get Set Go** is a cross-platform travel application built using **Flutter (Dart)** and powered by **Gemini AI** to offer users an enhanced, personalized travel experience. It generates intelligent travel itineraries and offers real-time query responses through an integrated AI chatbot.



## ✨ Features

- ✈️ **AI-Based Personalized Itineraries**  
  Get customized travel plans based on your interests, budget, and trip duration.

- 🤖 **Gemini API-Powered Chatbot**  
  Your 24/7 AI travel assistant that answers queries with high accuracy.

- 📍 **Smart Local Suggestions**  
  Get recommendations for restaurants, attractions, hotels, and events near your location.

- 📱 **Built with Flutter**  
  Smooth, fast performance on both **Android** and **iOS** devices.



## 🛠️ Tech Stack

| Component       | Technology         |
|-|--|
| Frontend       | Flutter (Dart)     |
| AI Integration | Gemini API         |
| Backend        | Firebase |



## 📦 Installation

### Prerequisites:
- Flutter SDK installed
- Android Studio or VS Code
